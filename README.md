# 쿠팡 · 네이버 광고 리포트

쿠팡/네이버에서 받은 광고 raw 데이터(csv 또는 xlsx)를 이 저장소에 올려두면,
**어느 컴퓤터에서든 브라우저 주소 하나로** 쿠팡/네이버 탭을 오가며 성과
표를 보고, 원본 파일도 그대로 다운로드할 수 있게 만든 저장소입니다.

## 처음 한 번만: GitHub Pages 켜기

리포트를 인터넷 주소로 열어보려면, 저장소 관리자가 딱 한 번만 아래 설정을 켜주면 됩니다.

1. 이 저장소의 GitHub 웹페이지에서 **Settings** 탭 클릭
2. 왼쪽 메뉴에서 **Pages** 클릭
3. **Build and deployment → Source**를 `Deploy from a branch`로 설정
4. **Branch**를 `main` / `(root)`으로 선택 후 **Save**
5. 1~2분 뒤, 같은 페이지에 뜨는 주소
   (예: `https://<계정명>.github.io/SSE_data_raw/`)로 접속하면 리포트가 보입니다.

이 주소는 로그인이나 별도 설치 없이 **어떤 컴퓤터의 브라우저에서든** 열립니다.

> 이 저장소는 현재 공개(Public)로 설정되어 있습니다. 즉, URL만 알면
> 누구나 raw 데이터(광고비, 캠페인명 등)를 볼 수 있습니다. 비공개로 되돌리고
> 싶다면 말씀해주세요 — GitHub Pro 결제 또는 별도 무료 호스팅 연결 등
> 대안을 안내해드릴 수 있습니다.

## 데이터 올리는 방법 (수동)

1. `data/coupang` 또는 `data/naver` 폴더로 들어갑니다.
2. **Add file → Upload files** 클릭
3. 쿠팡 Wing / 네이버 검색광고에서 받은 raw 파일(csv 또는 xlsx)을 변환 없이
   그대로 끌어다 놓습니다.
4. **Commit changes**로 저장합니다.

몇 분 안에 GitHub Actions가 자동으로 `data/manifest.json`을 갱신하고,
리포트 페이지를 새로고침하면 새 데이터가 바로 보입니다.
(자세한 안내는 `data/coupang/README.md`, `data/naver/README.md` 참고)

## 리포트 페이지에서 할 수 있는 것

- 상단 **쿠팡 / 네이버 탭**으로 화면 전환 (플랫폼별로 따로 봄)
- 맨 위 **"업로드된 파일"** 공지창에서 지금 어떤 raw 파일이 반영되어 있는지
  확인 (여기서는 다운로드 제공 안 함 — 원본은 맨 아래에서만 받을 수 있음)
- csv와 xlsx 파일을 변환 없이 그대로 인식
- 파일명으로 **광고상품 구분**(쿠팡 PA/BPA/NCA, 네이버 쇼핑검색광고(카탈로그)/
  애드부스트/카탈로그)을 자동으로 인식해서 표에 "상품구분" 컬럼으로 보여줍니다.
  상품마다 raw 컬럼 구성이 달라도 알아서 매칭하고, 캠페인명/그룹명이 상품 간에
  우연히 같아도 서로 다른 상품이면 집계가 섞이지 않습니다.
- **필터(슬라이서)**: 년도 / 월 / 광고상품유형 버튼을 눌러서 아래 표1~4를
  원하는 조건으로만 좁혀볼 수 있습니다. 여러 개 동시 선택 가능(예: 2026년 +
  9월 + PA), 아무것도 안 누르면 전체 기간/전체 상품이 보입니다. 필터 선택은
  탭(쿠팡/네이버)마다 따로 기억됩니다.
- 광고비·노출·클릭·CTR·CPC·전환수·전환매출·CVR·객단가·ROAS를 자동 계산해서
  아래 4개 표로 보여줍니다 (탭마다, 필터 조건에 맞게 따로 계산):
  - **표1. 전체기간의 지표** — 상품구분+캠페인명+그룹명별 전체기간 합산 (날짜 제외)
  - **표2. 광고상품별 지표 (전체기간)** — 상품구분(PA/BPA/NCA 등)별 합산, 전환매출 높은 순
  - **표3. 주차별, 광고상품별 지표** — 월~일 단위 주차 × 상품구분별 합산
  - **표4. 우수 판매 TOP10 상품** — 상품(쿠팡 PA는 판매 상품명, BPA/NCA는
    캠페인명, 네이버 애드부스트는 상품명, 카탈로그는 광고그룹명 기준)별
    전환매출 상위 10개
- **이 화면을 엑셀 파일로 다운받기**: 쿠팡/네이버 시트 2개짜리 엑셀 파일로,
  각 시트 안에 표1~4가 그대로 들어있는 파일을 받을 수 있습니다 (지금 선택된
  필터 조건이 그대로 반영됩니다)
- **원본 다운로드**: 맨 아래 섹션에서 현재 탭의 raw 파일을 그대로 다운로드

## 폴더 구조

```
index.html                 리포트 페이지 (GitHub Pages가 이 파일을 보여줌)
assets/                    리포트 페이지의 스타일/스크립트
data/coupang/*.csv|xlsx    쿠팡 raw 데이터 (수동 업로드)
data/naver/*.csv|xlsx      네이버 raw 데이터 (수동 업로드)
data/manifest.json         어떤 파일이 있는지 자동 생성되는 목록 (직접 수정 X)
scripts/build_manifest.py  manifest.json을 만드는 스크립트
.github/workflows/update-manifest.yml   파일 업로드 시 manifest.json 자동 갱신
```

## 참고

- raw csv 인코딩이 EUC-KR(CP949)이어도, xlsx의 날짜가 엑셀 숫자 형식
  (예: 46266) 이든 YYYYMMDD 숫자(예: 20260914)든 리포트가 자동으로
  인식해서 읽습니다.
- 지표 컬럼은 `assets/app.js`의 `FIELD_MAP`에 플랫폼×상품 기준으로 실제
  raw 컬럼명을 지정해서 계산합니다. 같은 개념도 상품마다 표기가 달라서
  (예: 광고비 / 집행 광고비 / 광고비(원)) 후보를 여러 개 등록해두고,
  그래도 안 맞으면 공백을 지우고 한 번 더 비교합니다.
  - 쿠팡 PA/BPA/NCA: 날짜/캠페인명/광고그룹/광고비/노출수/클릭수/
    직접 판매수량(1일)/직접 전환매출액(1일) 확정
  - 네이버 쇼핑검색광고(카탈로그)/애드부스트/카탈로그: 날짜/캠페인/그룹/
    총비용/노출수/클릭수/구매완료 수/구매완료 전환매출액 확정. 단
    쇼핑검색광고(카탈로그) 리포트는 raw 자체에 전환/매출 컬럼이 없어서
    그 파일에서는 전환수·전환매출·CVR·객단가·ROAS가 항상 "-"로 나옵니다
    (정상 동작).
  - 위 목록에 없는 새로운 raw 파일이 올라오면 컬럼명 패턴으로 최대한
    자동 추정하되, 실제 컬럼명을 알려주시면 더 정확하게 고정해 드릴 수
    있어요.
