# 쿠팡 · 네이버 광고 리포트

쿠팡/네이버에서 받은 광고 raw 데이터(csv, xlsx 또는 xlsb)를 이 저장소에 올려두면,
**어느 컴퓤터에서든 브라우저 주소 하나로** 쿠팡/네이버 탭을 오가며 성과
표를 보고, 원본 파일도 그대로 다운로드할 수 있게 만든 저장소입니다.

## 처음 한 번만: GitHub Pages 켜기

리포트를 인터넷 주소로 열어보려면, 저장소 관리자가 딱 한 번만 아래 설정을 켜주면 됩니다.

1. 이 저장소의 GitHub 웹페이지에서 **Settings** 탭 클릭
2. 왼쪽 메뉴에서 **Pages** 클릭
3. **Build and deployment → Source**를 `Deploy from a branch`로 설정
4. **Branch**를 `main` / `(root)`으로 선택 후 **Save**
5. 1~2분 뒤, 같은 페이지에 뜨는 주소
   (예: `https://<계정명>.github.io/SSE_data_raw/`)로 접속하면 리포트가 보입니다.

이 주소는 로그인이나 별도 설치 없이 **어떤 컴퓤터의 브라우저에서든** 열립니다.

> 이 저장소는 현재 공개(Public)로 설정되어 있습니다. 즉, URL만 알면
> 누구나 raw 데이터(광고비, 캠페인명 등)를 볼 수 있습니다. 비공개로 되돌리고
> 싶다면 말씀해주세요 — GitHub Pro 결제 또는 별도 무료 호스팅 연결 등
> 대안을 안내해드릴 수 있습니다.

## 데이터 올리는 방법 (수동)

1. `data/coupang` 또는 `data/naver` 폴더로 들어갑니다.
2. **Add file → Upload files** 클릭
3. 쿠팡 Wing / 네이버 검색광고에서 받은 raw 파일(csv, xlsx 또는 xlsb)을 변환
   없이 그대로 끌어다 놓습니다.
4. **Commit changes**로 저장합니다.

몇 분 안에 GitHub Actions가 자동으로 `data/manifest.json`을 갱신하고
(쿠팡 PA 키워드 리포트처럼 수십만 행짜리 파일은 키워드 단위만 미리 합친
가벼운 버전과, 다운로드에 필요한 컬럼만 남긴 버전을 `data/cache/`에 같이
만들어서, 브라우저는 큰 원본을 직접 해석하지 않고 그걸 읽습니다 - 모바일에서도
가볍게 열리도록. 폴더 이름이 `_`로 시작하면 GitHub Pages가 배포하지 않으므로
`cache`로 둡니다),
리포트 페이지를 새로고침하면 새 데이터가 바로 보입니다.
(자세한 안내는 `data/coupang/README.md`, `data/naver/README.md` 참고)

쿠팡 캠페인을 "품목"(냉장고, 청소기, TV 등) 단위로 묶어서 보고 싶다면
`INDEX` 폴더에 분류표 엑셀 파일을 올려주세요. 자세한 내용은
`INDEX/README.md` 참고.

## 리포트 페이지에서 할 수 있는 것

- 페이지를 열면 상단에 **"raw 데이터를 불러오는 중입니다..."** 안내가 뜹니다.
  raw 파일을 전부 내려받아서 브라우저에서 직접 해석하는 방식이라, 파일이
  크면(쿠팡 PA 키워드 리포트처럼 한 파일에 수만~수십만 행이 있는 경우) 처음
  여는 데 몇 초~십수 초 걸릴 수 있습니다. 표가 비어 보여도 이 안내가 떠있는
  동안은 고장이 아니라 불러오는 중인 것이니 기다려주시면 됩니다. 다 불러오면
  안내가 자동으로 사라집니다.
- 상단 **쿠팡 / 네이버 탭**으로 화면 전환 (플랫폼별로 따로 봄)
- 맨 아래 **"업로드된 파일"** 공지창에서 지금 어떤 raw 파일이 반영되어 있는지
  확인 (여기서는 다운로드 제공 안 함 — 원본은 바로 위 "원본 다운로드"에서만
  받을 수 있음)
- csv, xlsx, xlsb 파일을 변환 없이 그대로 인식
- 파일명으로 **광고상품 구분**(쿠팡 PA/BPA/NCA, 네이버 쇼핑검색광고(카탈로그)/
  애드부스트/카탈로그)을 자동으로 인식해서 표에 "상품구분" 컬럼으로 보여줍니다.
  상품마다 raw 컬럼 구성이 달라도 알아서 매칭하고, 캠페인명/그룹명이 상품 간에
  우연히 같아도 서로 다른 상품이면 집계가 섞이지 않습니다.
- **필터(슬라이서)**: 년도 / 월 / 광고상품유형 / 품목 버튼을 눌러서 아래
  표1~4를 원하는 조건으로만 좁혀볼 수 있습니다. 여러 개 동시 선택 가능(예:
  2026년 + 9월 + PA + 청소기), 아무것도 안 누르면 전체 기간/전체 상품이
  보입니다. 필터 선택은 탭(쿠팡/네이버)마다 따로 기억됩니다. 품목 슬라이서는
  `INDEX` 폴더의 분류표로 찾은 값이라 쿠팡 탭에서만 나타나고, 네이버
  탭에서는 비어있습니다.
- 광고비·노출·클릭·CTR·CPC·전환수·전환매출·CVR·객단가·ROAS를 자동 계산해서
  아래 4개 표로 보여줍니다 (탭마다, 필터 조건에 맞게 따로 계산). **네이버
  광고비는 raw의 "총비용"(VAT 포함 금액으로 추출됨)을 1.1로 나눈 VAT 제외
  금액**이고, 쿠팡 광고비는 raw 그대로(원래 VAT 제외)입니다. CPC·ROAS 등도
  이 VAT 제외 광고비로 계산됩니다. 반면 다운로드 파일 중 "VAT포함"이라고
  적힌 컬럼(쇼핑검색광고(카탈로그형) RAW의 총비용 등)은 raw 그대로 둡니다.
  아래 4개 표는 다음과 같습니다:
  - **표1. 전체기간의 지표** — 전체기간 합산 (날짜 제외).
    - 쿠팡: 상품구분/캠페인/그룹명 없이 `INDEX` 폴더의 품목 분류표로 찾은
      **품목** 기준으로만 묶습니다(상품구분이 달라도 같은 품목이면 합산).
      분류표에 없는 캠페인은 "미분류"로 표시됩니다. 매칭 규칙은
      `INDEX/README.md` 참고.
    - 네이버: 품목 분류 데이터가 없어서 상품구분+캠페인명 기준입니다
      (그룹명 구분 없이 합산).
  - **표2. 광고상품별 지표** — 상품구분(PA/BPA/NCA 등)별 합산, 전환매출 높은 순
  - **표3. 주차별 지표** — 월~일 단위 주차별 합산(상품구분 구분 없이 전체
    합산). 맨 아래에 가장 최근 주차 2개의 증감율(%)을 한 줄 더 보여줍니다
    (예: 최근주/그 전주 - 1).
  - **표4. 우수 판매 TOP10 상품** — 상품(쿠팡 PA는 판매 상품명, BPA는
    캠페인명, NCA는 광고명, 네이버 애드부스트는 상품명, 카탈로그는
    광고그룹명 기준)별 전환매출 상위 10개. NCA는 캠페인 하나가 "10월
    브랜드위크_모바일(상품소재)"처럼 여러 상품을 묶은 기획전인 경우가
    많아서, 캠페인명 대신 실제 광고 소재 단위인 **광고명**으로 상품을
    구분합니다.
- **리포트RAW 다운받기**: 맨 아래 "원본 다운로드" 섹션에 있습니다. 쿠팡 raw
  데이터로 5개 시트짜리 엑셀을 한 번에 받습니다. 키워드 단위 raw(CE_RAW/
  MX_RAW, 쿠팡 키워드_RAW)는 모바일 등 메모리가 적은 기기에서도 평소
  화면이 가볍게 유지되도록 평소에는 메모리에 들고 있지 않고, 이 버튼을
  누른 시점에 `data/cache/`의 다운로드용 파일을 받아서 만듭니다. CE_RAW가
  원본 그대로 수십만 행이라, 누르면 버튼이 "리포트 준비 중..."으로 바뀌면서
  PC에서도 수십 초 걸릴 수 있습니다(모바일에선 메모리가 부족할 수 있음).
  - **CE_RAW / MX_RAW**: `리포트양식/CE_MX_주간RAW_양식.xlsb`과
    같은 25개 컬럼 구성(날짜/구분/광고유형/품목/캠페인/광고비/노출/클릭/
    판매수량·전환매출액(1일·14일, 총/직접)/세부품목). 품목이 웨어러블/
    모바일이면 MX, 그 외 알려진 품목이면 CE로 자동 분류합니다.
  - **쿠팡_RAW**: `리포트양식/쿠팡상품광고_월간리포트양식RAW.xlsb`과 같은
    모양(월간 집계라 날짜 대신 집행년/집행월 단위). 집행년+집행월+구분+
    품목명+광고유형+캠페인명+세부품목 단위로 합산. "예산처" 컬럼은 저희
    쪽에 원본 데이터가 없어서 값은 채우지 않고 항상 빈 칸으로 둡니다.
  - **쿠팡_전환상품_RAW**: 같은 월간리포트양식RAW 파일과 같은 모양(월간
    집계). 집행년+집행월+상품구분+캠페인ID+캠페인명+상품(VIID)+상품명
    단위로 키워드 구분 없이 합산 (구분(CE/MX) 컬럼 포함)
  - **쿠팡 키워드_RAW**: 키워드가 있는 PA만 대상으로, 월별로(년+월+
    캠페인ID+캠페인명+상품(VIID)+키워드 단위, 일자·상품명 구분 없이) 합산
  - "미분류"(INDEX 분류표에 없는 캠페인)는 어느 사업부 매출인지 알 수
    없어서 5개 시트 어디에도 포함하지 않습니다. 지금 쿠팡 탭에 선택된
    필터 조건이 반영됩니다.
  - 받은 파일의 각 시트를 CE_MX_주간RAW_양식.xlsb, 쿠팡상품광고_월간리포트양식RAW.xlsb의
    같은 이름 시트에 그대로 복사해 넣고 쓰면 됩니다.
  - 피벗테이블 시트는 자동으로 채워주지 않습니다 - 브라우저에서 쓰는
    라이브러리가 엑셀 피벗테이블 생성을 지원하지 않아서, 실제 운영 파일의
    바이너리를 직접 건드리는 대신 그 피벗이 보여주는 숫자를 똑같이
    계산해서 별도 파일로 드리는 방식을 택했습니다. 피벗 시트는 양식
    파일을 열어서 직접 새로고침해주세요.
  - 쿠팡 탭에서만 보입니다.
- **GFA리포트RAW 다운받기**: 역시 "원본 다운로드" 섹션에 있고, **네이버
  탭에서만** 보입니다. `리포트양식/네이버_GFA_RAW_양식.xlsb`의
  "GFA_캠페인RAW"/"GFA_상품RAW" 시트와 같은 모양으로 2개 시트짜리 엑셀을
  받습니다 (월간 집계라 날짜 대신 집행 년/월 단위입니다).
  - **GFA_캠페인RAW**: 캠페인ID가 있는 애드부스트·카탈로그만 대상으로,
    집행년+집행월+캠페인ID+캠페인명+광고유형 단위로(그룹/상품 구분 없이)
    합산
  - **GFA_상품RAW**: 쇼핑몰 상품 ID가 있는 애드부스트만 대상으로, 집행년+
    집행월+캠페인명+상품ID 단위로 합산
  - **품목명**(GFA_상품RAW는 모델명도)은 `네이버_GFA_RAW_양식.xlsb` 안의
    캠페인ID/상품코드 → 품목구분 조회표(각각 O~S열, P~U열)로 채웁니다.
    같은 캠페인ID/상품코드라도 달이 바뀌면 다른 품목으로 다시 쓰이는
    경우가 실제로 있어서, 집행월까지 포함해서 조회합니다. 조회표에 없으면
    "미분류"로 표시합니다(쿠팡 쪽과 달리 제외하지 않고 그대로 넣습니다).
  - 쇼핑검색광고(카탈로그)는 캠페인ID/상품ID 자체가 없어서 두 시트 모두
    포함되지 않습니다.
  - "광고비(-VAT)"는 "총비용(VAT포함,원)"을 1.1로 나눈 값입니다(네이버 raw
    추출 시 총비용에 VAT가 포함되어 내려옵니다).
- **쇼핑검색광고(카탈로그형) RAW 다운받기**: 역시 "원본 다운로드" 섹션에
  있고, **네이버 탭에서만** 보입니다. `리포트양식/네이버_쇼핑검색광고_
  월간리포트양식RAW.xlsb`의 "네이버_RAW"/"네이버 키워드_RAW" 시트와 같은
  기준으로 2개 시트짜리 엑셀을 받습니다(월간 집계).
  - **네이버_RAW**: 쇼핑검색광고(카탈로그) 일별 리포트(PC/모바일 매체·
    시간대별까지 쪼개진 것)를 집행년+집행월+캠페인+광고그룹+PC/MO+시간대
    단위로 합산합니다. 평균노출순위는 노출수로 가중평균합니다. "품목명"/
    "모델명"은 raw에 상품/모델 컬럼이 아예 없고, 캠페인명/광고그룹명 표기
    방식이 캠페인마다 달라서(자동 생성된 "CN~.../FF~..._BS~..." 코드형
    vs. 수동으로 "쇼핑검색_<품목>"처럼 지은 이름형) 추측으로 채우면 사업부
    집계가 틀릴 위험이 있어 비워둡니다. 대신 뒤쪽에 "참고_캠페인"/
    "참고_광고그룹" 2개 컬럼을 추가해서, 대시보드 표1(캠페인명/그룹명 표시)
    과 맞춰보고 품목명/모델명을 직접 채워 넣을 수 있게 했습니다.
  - **네이버 키워드_RAW**: `data/naver`에 올라온 "...쇼핑검색광고_검색어_
    RAW_..." 리포트(캠페인/광고그룹/검색어/노출수/클릭수/총비용 - 행에
    날짜 컬럼이 없고 파일명의 날짜 범위로 집행년/월을 구함)를 집행년+
    집행월+광고그룹+검색어 단위로 합산합니다. "모델명"은 이 리포트의
    광고그룹 값이 이미 상품 모델코드라 그대로 옮기고, "품목"은 역시 분류
    판단이 필요해 비워둡니다(모델명으로 대시보드와 맞춰보고 채울 수
    있습니다).

```

data/coupang/*.csv|xlsx|xlsb   쿠팡 raw 데이터 (수동 업로드)

INDEX/*.xlsb|xlsx          쿠팡 캠페인 품목 분류표 (수동 업로드)

```

## 참고

- raw csv 인코딩이 EUC-KR(CP949)이어도, xlsx의 날짜가 엑셀 숫자 형식
  (예: 46266) 이든 YYYYMMDD 숫자(예: 20260914)든 리포트가 자동으로
  인식해서 읽습니다.
- 지표 컬럼은 `assets/app.js`의 `FIELD_MAP`에 플랫폼×상품 기준으로 실제
  raw 컬럼명을 지정해서 계산합니다. 같은 개념도 상품마다 표기가 달라서
  (예: 광고비 / 집행 광고비 / 광고비(원)) 후보를 여러 개 등록해두고,
  그래도 안 맞으면 공백을 지우고 한 번 더 비교합니다.
  - 쿠팡 PA/BPA/NCA: 날짜/캠페인명/광고그룹/광고비/노출수/클릭수/
    직접 판매수량(1일)/직접 전환매출액(1일) 확정
  - 네이버 쇼핑검색광고(카탈로그)/애드부스트/카탈로그: 날짜/캠페인/그룹/
    총비용/노출수/클릭수/구매완료 수/구매완료 전환매출액 확정. 단
    쇼핑검색광고(카탈로그) 리포트는 raw 자체에 전환/매출 컬럼이 없어서
    그 파일에서는 전환수·전환매출·CVR·객단가·ROAS가 항상 "-"로 나옵니다
    (정상 동작).
  - 위 목록에 없는 새로운 raw 파일이 올라오면 컬럼명 패턴으로 최대한
    자동 추정하되, 실제 컬럼명을 알려주시면 더 정확하게 고정해 드릴 수
    있어요.
- 네이버 쇼핑검색광고(카탈로그) 다운로드처럼 실제 헤더 위에 "리포트 제목,ID"
  한 줄이 더 붙어있는 csv도 자동으로 그 줄을 건너뛰고 읽습니다. 이 리포트는
  PC/모바일·시간대별로 잘게 쪼개진 원본이라도, 시간대 구분 없이 캠페인+그룹
  기준으로 자동 합산되어 표에 나타납니다.
