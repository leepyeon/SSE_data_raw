# 쿠팡 광고 raw 데이터 업로드 폴더

쿠팡 윙(Wing) 광고관리자에서 내려받은 **raw 리포트 csv 파일**을 이 폴더에
그대로 올려주세요.

## 올리는 방법 (수동)

1. 이 저장소를 GitHub 웹사이트에서 엽니다.
2. `data/coupang` 폴더로 들어갑니다.
3. **Add file → Upload files** 버튼을 누르고, 쿠팡에서 받은 csv 파일을
   그대로 끌어다 놓습니다.
4. 하단의 **Commit changes** 버튼을 눌러 저장합니다.

파일명은 자유롭게 지어도 되지만, 날짜를 포함하면 나중에 찾기 편합니다.
예: `2026-09-01_coupang_report.csv`

업로드하면 몇 분 안에 리포트 웹페이지에 자동으로 반영됩니다
(내부적으로 `data/manifest.json`이 자동 갱신됩니다).
