# INDEX 폴더 (쿠팡 품목 분류표)

쿠팡 캠페인들을 "품목"(예: 냉장고, 청소기, TV 등) 단위로 분류해둔 엑셀
파일(xlsb/xlsx)을 올려두는 폴더입니다. 리포트의 **쿠팡 탭 표1**이 이
파일을 읽어서 캠페인&그룹 대신 품목 기준으로 지표를 묶어서 보여줍니다.

## 파일 형식

- 한 시트 안에 서로 독립된 두 개의 조회표가 나란히 들어있는 구조를
  그대로 지원합니다.
  - **B~F열**: 캠페인명 / **캠페인 ID** / 그룹명 / **품목** / 세부품목
  - **H~L열**: 캠페인명 / **VIID** / 상품명 / **품목** / 세부품목
- 1행은 헤더, 2행부터 데이터입니다.

## 매칭 규칙

캠페인ID/캠페인명/그룹명/VIID를 **각각 단독 키로**(조합하지 않고) 순서대로
조회합니다. 상품구분(PA/BPA/NCA)마다 순서가 다릅니다.

- **PA**: 1순위 캠페인ID → 2순위 캠페인명 → 3순위 그룹명 → 4순위 VIID(광고집행 옵션ID)
- **BPA**: 1순위 캠페인명 → 2순위 그룹명
- **NCA**: 캠페인명

캠페인ID/캠페인명/그룹명은 B~F열에서, VIID는 H~L열에서 조회합니다.
끝까지 못 찾으면 **"미분류"**.

## 알아두면 좋은 점

- 캠페인ID(또는 캠페인명/그룹명) 하나에 품목이 여러 개로 갈리는 행이
  있으면(예: 여러 상품군을 묶은 기획전 캠페인), 그 키로는 그중 하나만
  대표로 매칭됩니다. 그룹까지 함께 보고 싶다면 그 캠페인/그룹의 정확한
  품목을 이 파일에 다시 한 번 확인해서 데이터를 정리해주세요.
- **BPA**는 캠페인ID/VIID는 보지 않고 캠페인명 → 그룹명 순서로만
  조회합니다.
- **NCA**는 raw에 캠페인명만 있어서 캠페인명으로만 조회합니다.
- 같은 이름의 새 파일을 올리면(예: `INDEX_261028.xlsb`) 파일명 기준으로
  가장 최신 파일 하나만 사용합니다. 예전 파일은 지우지 않아도 됩니다.
- 여기 파일을 새로 올리거나 바꾸면 GitHub Actions가 자동으로
  `data/manifest.json`을 갱신하고, 리포트를 새로고침하면 바로 반영됩니다.
