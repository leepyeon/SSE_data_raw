# INDEX 폴더 (쿠팡·네이버 품목 분류표)

쿠팡·네이버 캠페인들을 "품목"(예: 냉장고, 청소기, TV 등) 단위로 분류해둔 엑셀
파일(xlsb/xlsx)을 올려두는 폴더입니다. 대시보드의 품목 필터, **품목별 데이터**
표, 판매 우수 상품(네이버는 모델명), 리포트RAW/GFA/쇼핑검색 다운로드의 품목·
모델명이 이 파일을 씁니다. 파일명 기준으로 가장 최신 파일 하나만 씁니다.

## 파일 형식

### 쿠팡상품광고 시트 (없으면 첫 시트)

- 한 시트 안에 서로 독립된 두 개의 조회표가 나란히 들어있는 구조를
  그대로 지원합니다.
  - **B~F열**: 캠페인명 / **캠페인 ID** / 그룹명 / **품목** / 세부품목
  - **H~L열**: 캠페인명 / **VIID** / 상품명 / **품목** / 세부품목
- 1행은 헤더, 2행부터 데이터입니다.

### 네이버_GFA 시트 (GFA 애드부스트·카탈로그)

- 컬럼: 캠페인 목적 / **캠페인 ID** / 캠페인명 / **품목** / SOP / **상품명**
- RAW의 캠페인 ID로 품목과 모델명(상품명 컬럼)을 찾습니다.
- 애드부스트(ADVoost 쇼핑)처럼 상품명이 **"-"**이면 모델명은 RAW 파일의
  "상품명"에서 가져옵니다. 카탈로그는 GFA 주간리포트 양식 기준에 맞춰 이 시트의
  **SOP로 "카탈로그_SOP명"**(예: 카탈로그_유니씨앤씨)을 만들어 씁니다(상품명 칸 값은
  쓰지 않으므로 SOP를 정확히 적어주세요).
- 이 시트에 없는 캠페인은 리포트양식 GFA 양식의 조회표(월+캠페인 ID)로 한 번 더
  찾고, 그래도 없으면 "미분류"(대시보드 모델명은 "미분류 · 캠페인명")입니다.

### 네이버_쇼핑검색광고 시트

- 컬럼: **캠페인** / **광고그룹** / **품목명** / **모델명**
- RAW의 캠페인+광고그룹으로 품목과 모델명을 찾습니다.

## 매칭 규칙

캠페인ID/캠페인명/그룹명/VIID를 **각각 단독 키로**(조합하지 않고) 순서대로
조회합니다. 상품구분(PA/BPA/NCA)마다 순서가 다릅니다.

- **PA**: 1순위 캠페인ID → 2순위 캠페인명 → 3순위 그룹명 → 4순위 VIID(광고집행 옵션ID)
- **BPA**: 1순위 캠페인ID → 2순위 그룹명
- **NCA**: 캠페인명

캠페인ID/캠페인명/그룹명은 B~F열에서, VIID는 H~L열에서 조회합니다.
끝까지 못 찾으면 **"미분류"**.

## 알아두면 좋은 점

- **여러 품목에 걸친 그룹명은 조회에 안 씁니다.** 쿠팡 기본 그룹명인
  "새 광고 그룹"처럼 이 파일에서 서로 다른 품목(TV, 청소기, 냉장고 등)에 같이
  쓰인 그룹명은 그 이름만으로는 품목을 알 수 없어서 건너뛰고 다음 기준(PA는
  VIID)으로 찾습니다. 그래도 없으면 "미분류"입니다. 예전에는 이 경우 파일의
  마지막 "새 광고 그룹" 행(전기레인지_증분테스트) 품목으로 잘못 분류됐습니다.
  품목은 같고 세부품목만 다른 그룹명(예: "세탁기")은 그대로 씁니다.
- **새 캠페인을 만들면 이 파일에 캠페인ID를 꼭 추가해 주세요.** 그룹명을
  "새 광고 그룹"으로 두는 캠페인은 캠페인ID/캠페인명이 없으면 VIID로만
  찾을 수 있어서, VIID까지 없으면 "미분류"가 됩니다. 대시보드 품목 필터에
  "미분류"가 보이면 이 파일에 빠진 캠페인이 있다는 뜻입니다.
- 캠페인ID(또는 캠페인명/그룹명) 하나에 품목이 여러 개로 갈리는 행이
  있으면(예: 여러 상품군을 묶은 기획전 캠페인), 그 키로는 그중 하나만
  대표로 매칭됩니다. 그룹까지 함께 보고 싶다면 그 캠페인/그룹의 정확한
  품목을 이 파일에 다시 한 번 확인해서 데이터를 정리해주세요.
- **BPA**는 캠페인명/VIID는 보지 않고 캠페인ID → 그룹명 순서로만
  조회합니다.
- **NCA**는 raw에 캠페인명만 있어서 캠페인명으로만 조회합니다. 단, 캠페인이
  "[NCA] 10월 브랜드위크_의류케어(...)"처럼 세탁기/건조기 광고를 하나로
  묶은 기획전이라 품목이 "의류케어"로 잡히면, 캠페인명 대신 실제 광고 소재
  단위인 **광고명** 컬럼 텍스트로 세부품목을 다시 가릅니다: 광고명에
  "건조기"가 있으면 세부품목 "건조기", "콤보"가 있으면 "세탁기"(그 외엔
  이 파일의 세부품목 값을 그대로 씁니다).
- **의류케어 상품별 세부품목**: 품목이 "의류케어"인 광고 중 아래 광고집행
  상품은 세부품목을 상품 단위로 다시 나눕니다(이 파일은 캠페인/VIID 기준이라
  상품 단위로는 못 가르기 때문). 목록은 `assets/app.js`의
  `LAUNDRY_SUBITEM_PRODUCTS`에 있고, 상품명 전체 또는 모델코드(상품명 다음
  칸들)가 같으면 해당 세부품목이 됩니다. 목록에 없는 상품은 이 파일 값 그대로.
  - 세탁기: 그랑데 드럼세탁기 21kg/19kg, 그랑데 통버블 세탁기 10kg/16kg/21kg,
    AI 세탁기 25kg(블랙/화이트), AI 통버블 일반 세탁기 19kg, 그랑데 AI 세탁기 12kg
  - 건조기: AI 건조기 21kg(블랙/화이트), 건조기 9kg, 인버터 건조기 9kg
  - 세건패키지: BESPOKE 그랑데 AI 원바디 Top Fit(2종), 비스포크 그랑데 AI
    세탁기+건조기, AI 세탁기+건조기+직렬설치키트(2종), Bespoke AI 콤보
    세탁건조기(3종)
  - 에어드레서: Bespoke 에어드레서(DF18CB8600ER)
- 같은 이름의 새 파일을 올리면(예: `INDEX_261028.xlsb`) 파일명 기준으로
  가장 최신 파일 하나만 사용합니다. 예전 파일은 지우지 않아도 됩니다.
- 여기 파일을 새로 올리거나 바꾸면 GitHub Actions가 자동으로
  `data/manifest.json`을 갱신하고, 리포트를 새로고침하면 바로 반영됩니다.
