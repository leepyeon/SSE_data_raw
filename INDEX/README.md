# INDEX 폴더 (쿠팡 품목 분류표)

쿠팡 캠페인들을 "품목"(예: 냉장고, 청소기, TV 등) 단위로 분류해둔 엑셀
파일(xlsb/xlsx)을 올려두는 폴더입니다. 리포트의 **쿠팡 탭 표1**이 이
파일을 읽어서 캠페인&그룹 대신 품목 기준으로 지표를 묶어서 보여줍니다.

## 파일 형식

- 한 시트 안에 서로 독립된 두 개의 조회표가 나란히 들어있는 구조를
  그대로 지원합니다.
  - **B~F열**: 캠페인명 / **캠페인 ID** / 그룹명 / **품목** / 세부품목
  - **H~L열**: 캠페인명 / **VIID** / 상품명 / **품목** / 세부품목
- 1행은 헤더, 2행부터 데이터입니다.

## 매칭 규칙

쿠팡 raw의 한 행(캠페인)을 다음 순서로 조회해서 품목을 정합니다.

1. **캠페인ID + 그룹명**이 동시에 일치하는 행이 있으면 그 품목 사용
   (같은 캠페인이라도 그룹(세부 프로모션)별로 품목이 갈리는 경우 대응)
2. 위에서 못 찾았고, 그 **캠페인ID의 품목이 항상 하나로 고정**되어 있으면
   (그룹과 무관하게 품목이 안 갈리는 캠페인) 그 품목 사용
3. 그래도 못 찾았으면 raw의 **VIID(광고집행 옵션ID)** 로 H~L열 조회
4. 끝까지 못 찾으면 **"미분류"**

## 알아두면 좋은 점

- **NCA**는 raw에 캠페인ID/VIID에 해당하는 컬럼이 전혀 없어서, NCA
  캠페인들은 항상 "미분류"로 표시됩니다.
- **BPA**는 캠페인ID 컬럼은 있지만 VIID에 해당하는 컬럼이 없어서, 3번
  단계(VIID 조회)는 항상 건너뜁니다.
- 같은 이름의 새 파일을 올리면(예: `INDEX_261028.xlsb`) 파일명 기준으로
  가장 최신 파일 하나만 사용합니다. 예전 파일은 지우지 않아도 됩니다.
- 여기 파일을 새로 올리거나 바꾸면 GitHub Actions가 자동으로
  `data/manifest.json`을 갱신하고, 리포트를 새로고침하면 바로 반영됩니다.
